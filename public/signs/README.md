# Sinais (LGA)
Coloca aqui imagens/GIFs/WebP validados por pessoas surdas, professores ou intérpretes de Língua Gestual Angolana.
Depois regista cada palavra em manifest.json (chave em minúsculas, sem acentos):

{
  "obrigado": { "file": "obrigado.webp", "validatedBy": "Nome ou associação que validou", "credit": "Autor/fonte" }
}

Sem "validatedBy" a entrada é ignorada. Não adiciones sinais de outras línguas gestuais como se fossem LGA.
